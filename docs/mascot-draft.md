# 神秘指南 · 看板娘草案（女性角色版）

> 文字版，未出图。五个方案，靠**年龄感／性格／记忆符号**三个维度区分。

## 一、硬约束（先定死，再谈形象）

| 软件特点 | 约束 |
|---|---|
| 暗紫金、克制 | 不用高饱和糖果色，不卖萌 |
| 每天两三分钟 | 不长篇说话，不做拦截式弹窗 |
| 成人用户、神秘学兴趣 | 不能幼稚化，不能像儿童教育 App |
| 内容考据型 | 她说的每句都要站得住，不许乱鼓励 |
| 单一记忆符号 | 视觉元素控制在三个以内 |

**底线**：她不能打断学习。任何要按「关闭」才能继续的东西都不做。

## 二、五个方案

### A｜守夜人（19–21 岁，安静型）

- **外形**：深紫长发（及腰），额前一枚小符印，深色长袍压细金线，手里一卷星图纸。身形偏瘦，站姿沉。
- **记忆符号**：**额前符印**。
- **性格**：话少，答得准，不夸人也不安慰，只给下一步。
- **台词**：「今天这节，两分钟。」「记下了。明天见。」「再看一遍那句。」
- **出现**：首页右下角常驻（80×80），学完一节说一句。其他时候不出现。
- **成本**：立绘 1 张 + 差分 3 张（平常／思考／困）。
- **风险**：二次元长发少女太多，要靠符印和配色拉辨识度。

### B｜学徒（16–18 岁，笨拙型）

- **外形**：栗色短发（略乱），总是抱着一摞歪掉的书，袖口沾着墨。袍子是改大的，不合身。
- **记忆符号**：**那摞书**（永远快掉了）。
- **性格**：好奇、爱问、会记错——她的"不完美"让用户敢承认自己不懂。
- **台词**：「这条我上次记反了，你也别记反。」「等等，我先翻一下……」
- **出现**：答错时、查资料时、书库里。
- **成本**：立绘 1 张 + 差分 4 张（抱着书／翻书／慌了／笑）。
- **风险**：笨拙型容易变成"卖蠢"，要克制——她只在该不懂的时候不懂。

### C｜星象师（28–32 岁，权威型）

- **外形**：深色长裙、金边圆眼镜、头发盘起用一根铜簪别住，手里一把黄铜量尺。
- **记忆符号**：**金边眼镜 + 铜量尺**。
- **性格**：冷静、有条理、说话像在下判断。不寒暄。
- **台词**：「这一节你没做完。」「按顺序来，别跳。」「数值不对，重算。」
- **出现**：课程页、实验课的验收环节。
- **成本**：立绘 1 张 + 差分 3 张（看尺／抬眼／皱眉）。
- **风险**：太严肃会让人不敢用，适合做"验收者"而不是"陪伴者"。

### D｜双生姐妹（一冷一热，都是女性）

- **外形**：姐姐（冷）深紫长发，妹妹（热）浅金短发，两人穿着同款不同色的袍子。
- **记忆符号**：**发色对比**（紫／金）。
- **性格**：姐姐克制、妹妹急躁，会互相吐槽。
- **台词**：妹妹「今天还没学呢。」姐姐「……她催我。」
- **出现**：姐姐常驻首页，妹妹只在"该学了"时冒出来。
- **成本**：**最高**，两套立绘两套差分。
- **风险**：两人要有化学反应，做不好就是两个都烦。

### E｜引路童（12–14 岁，神秘型）

- **外形**：小女孩，赤脚，穿短袍，提一盏小灯，眼睛颜色偏浅（异色）。
- **记忆符号**：**手里那盏灯**（灯是道具，不是本体）。
- **性格**：说话像谜语、句子短、偶尔说出超出年龄的话。不撒娇。
- **台词**：「灯往这边。」「你走错了。」「前面还有三节。」
- **出现**：进新课、进实验课时领路。
- **成本**：立绘 1 张 + 差分 3 张。
- **风险**：儿童形象在成人向 App 里容易被误读，需要靠气质压住。

## 三、对比

| | 年龄感 | 性格 | 记忆符号 | 成本 | 适合场景 |
|---|---|---|---|---|---|
| A 守夜人 | 19–21 | 安静克制 | 额前符印 | 中 | 首页陪伴 |
| B 学徒 | 16–18 | 好奇笨拙 | 一摞书 | 中 | 答疑、书库 |
| C 星象师 | 28–32 | 权威冷静 | 眼镜+量尺 | 中 | 验收、课程页 |
| D 双生 | 20 上下 | 一冷一热 | 发色对比 | 高 | 全场景 |
| E 引路童 | 12–14 | 神秘简短 | 一盏灯 | 中 | 领路、新课 |

## 四、我的建议

**主推 A（守夜人）**，理由：

1. 她跟 App 的气质最贴——安静、克制、答得准，不喧哗。用户是成年人，来学神秘学，不需要被哄。
2. 成本可控：一张立绘三张差分就够，不用 L2D。
3. **可扩展**：以后想要"活泼一点"，就加 B 当她的搭档（一静一动），不用推翻重做。
4. C 太硬，适合当"验收角色"而不是主形象；D 成本翻倍；E 的年龄感在成人向内容里要额外处理。

**如果只能选一个**：A。
**如果预算够做两个**：A + B（守夜人常驻，学徒在答疑时出现）。

## 五、定了之后要产出什么

1. 主立绘一张（正面全身，透明底）
2. 表情差分 3–5 张（只改眼和嘴，身体不动）
3. 尺寸：首页 80×80（半身裁切）、弹层 160×160、App 图标另做（不共用立绘）
4. 动效：CSS 呼吸（2 秒循环）+ 眨眼两帧交替，**不做 L2D**
5. 台词表：每个场景 3–5 句，总计不超过 20 句

## 六、台词红线

- 不说「你真棒」「加油哦」这类空话
- 不卖萌（「喵」「~」）
- 没话说的时候不说话
- 不用她推广告或引导评价
